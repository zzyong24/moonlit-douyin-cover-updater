# 中断、失败与续跑

恢复先读取队列、每条尝试回执和实际平台状态，不从第一条重新上传。

| 情况 | 恢复动作 |
| --- | --- |
| 上传窗口仍开着 | 看窗口比例和真实图；若图正确继续完成，若错误重新选对应文件 |
| 点完成后卡片未更新 | 等窗口关闭及主卡片异步更新；不在加载时提交 |
| 提交超时/工具报错 | 回作品管理并重开同ID，确认是否已经保存；已保存则验收，未保存才重试 |
| 双槽已保存、主页尚旧 | 保留submitted，刷新并记录实际时间；不重复消耗编辑机会 |
| 资源ID已变但图还是错 | 判未完成，保留错误尝试；剩余机会允许时只修该作品错误槽位 |
| verified条目源哈希变化 | 保留旧验收，建立新尝试；重新确认本次范围和文件映射 |
| 两槽资源ID相同 | 看是否错误复用了同一图/裁切；未确定前不提交 |
| 私密作品 | skipped_private，不打开写入流程，不改可见性 |
| 页面显示无编辑机会/拒绝 | blocked，记录实际提示；不删除重发或尝试绕过 |
| 登录失效/验证码/账号不符 | 停止账号写入，提示用户需要恢复的具体步骤 |
| 用户接管或要求停 | 保存当前位置和未完成比例，停止写入；等待新指示 |

一条失败不抹掉其他已核验作品。单条源文件缺失可继续整理其他作品；账号级阻断影响所有后续写入。重复失败不无限重试，每次重试都必须有新的状态观察及可解释的恢复条件。

修复顺序：当前作品错误 → 实际图像验收 → 更新历史与队列 → 汇总。经验写回行为所有者；用户一次性标题、账号和平台ID只留作品。公开版技能不附真实截图、已登录浏览器资料或历史用户批次。
